# 毎日のタスク管理ツール

シンプルなWebブラウザで動作するタスク管理ツールです。毎日のやることを管理できます。

## 機能

- ✅ **タスク追加**: 新しいタスクを入力して追加できます
- ✅ **タスク完了**: タスクをチェックして完了マークできます
- ✅ **タスク削除**: 不要なタスクは削除できます
- ✅ **自動保存**: ブラウザに自動的に保存されます

## 使い方

1. `index.html` をWebブラウザで開く
2. テキスト入力欄にやることを入力
3. 「追加」ボタンをクリック（またはEnterキーを押す）
4. 完了したらチェックボックスをクリック
5. 不要なタスクは「削除」ボタンで削除

## 技術

- HTML5
- CSS3
- JavaScript（localStorage で自動保存機能）

## インストール不要

特別なインストール不要！ `index.html` をダウンロードしてブラウザで開くだけで使えます。
